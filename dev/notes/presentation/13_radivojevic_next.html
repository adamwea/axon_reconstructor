🔬 Immediate (slice 3.6) — Stage 2: skeletonization
  1. core/electrical_image.py — build a 2D voltage map per upsampled timeframe by rasterizing electrode (x, y) onto a regular grid. Pixel size is a knob; default ~10 µm to roughly match electrode pitch.
  2. core/skeletonization.py — morphological thinning of each per-timeframe voltage image to a 1-pixel-wide centerline. scikit-image primitives + paper-spec post-processing (despur, prune short branches).
  3. core/stage_2.py — orchestrator: take Stage1Result peaks, build pair-averaged skeletons on-demand for each (frame_i, frame_j) link candidate. Output: per-pair skeleton dict consumed by Stage 3.

📐 Differential check (DC-001)

Numerical invariants required to pass before promotion off "provisional":

  • Identical inputs: merged_template byte-for-byte.
  • Similar size: arbor area within tolerance TBD by triage.
  • Similar branching: n_branches within tolerance.
  • Similar velocity: median + distribution comparable.
  • Similar soma localization: xy within µm tolerance.

Tolerances are set by the first comparison; subsequent runs measure against them.
