Radivojevic 2023 — algorithm overview PI MILESTONE

The Milos-style axon-tracking algorithm — clean-room re-implementation of Milos Radivojevic's Functional axonal morphology reconstruction from extracellular HD-MEA recordings (eLife 2023, DOI 10.7554/eLife.86512). No public code release; we reconstruct from the paper + supplemental methods. Alternative / complement to the current axon_velocity path.

📥 Inputs (compatible with current pipeline)
  • Spike-triggered average electrode_template[n_channels, n_samples] — same shape as our existing axon_velocity_gtrs inputs. Drop-in compat.
  • Electrode locations (x, y) µm.
  • Sampling rate — paper used MEA1k @ 20 kHz. We parameterize as upsample_factor (default 10×), not absolute Hz, so MaxTwo @ 10 kHz and MaxOne @ 20 kHz both work without hardcoding.
  • Spike sorting must already have happened (our spikesort stage handles this; current QC is KS4-native labels, bombcell bypassed).
📤 Outputs (target — same shape as axon_velocity_gtrs)
  • Per-axon branch trajectories (count + lengths).
  • Per-branch conduction velocities.
  • Soma localization (xy on chip).
  • Per-arbor signal-amplitude map.
  • Match-able to gtr-pkl format so existing plot_recons renders both algorithms identically.

Three-stage architecture

Stage 1 ✓ Adaptive thresholding

Detect signal peaks in the spatiotemporal STA. Operates on the time-derivative (µV/µs) of upsampled (10× Whittaker-Shannon) voltage. Three sub-steps:

  • Step 1: planar 9-STD threshold + local-max detection.
  • Step 2: confined 2-STD threshold within 50 µm + ±1 frame of step-1 peaks.
  • Step 3: confined 2-STD threshold within 50 µm of step-2 peaks (recursive).

Output: union of detected peaks with per-step source labels.

Stage 2 Skeletonization

Infer conduction pathways between detected peaks via image-processing on the 2D voltage maps:

  • Build per-timeframe 2D voltage images from electrode coordinates.
  • Morphological thinning to extract candidate connection skeletons.
  • Pair-averaged skeletonization on-demand (per the paper's two-stage routing logic).

Output: per-timeframe skeleton graph used by Stage 3.

Stage 3 Multi-step tracking

Interconnect peaks across consecutive timeframes with three strategies:

  • Direct matching — adjacent timeframes, short distance.
  • Skeleton-assisted routing — when direct fails, follow the Stage-2 skeleton.
  • Velocity-based indirect prediction — extrapolate forward from established velocity; cap distance to 400 µm.

Output: per-axon branching graph with timing.

Why we want it: axon_velocity (Buccino 2022) is graph-search-driven; Radivojevic is image-processing-driven. Different algorithmic priors. Different failure modes. Side-by-side comparison on the same templates tells us which arbors are algorithm-independent (real) and which are method artifacts. Also: clean-room implementation forces us to fully understand the algorithm, which clarifies the assumptions baked into the production path.
