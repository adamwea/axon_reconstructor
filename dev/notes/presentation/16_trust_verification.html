How we know it's right — verifier scaffold

Three-tier trust model anchored on user-pinned reference outputs. Tests are advisory; outputs are ground truth.

Trust tiers

TierWhat's in itAuthRole
1 · trusted User-pinned outputs. TR-000 blanket pin on the reference dir. TR-001 176-template regression. TR-002 unit_0598 gtr.pkl. TR-003 sample-rate metadata. TR-004 preprocess binary. User Ground truth. Any deviation needs explicit user OK.
2 · advisory Existing test suite (~457 tests across axon_recon + siblings). Demoted from blocking → advisory after observing tests-green ≠ feature-works-on-real-data. Maintained by loop Catches regressions in unit-level invariants. Doesn't certify real-data correctness.
3 · provisional New outputs from in-progress algorithms (e.g. Radivojevic Stage 1 output today). No reference yet. None Visual diagnostics + USER review gate; promoted to Tier 1 once stable.

The brain/ module — context-drift defense

Long-running autonomous loops drift. Defense is a small set of files re-read every iteration as the persistent goal slot:

Goal slot

objectives.md, current_state.md, open_questions.md. Goal-attractor that biases everything downstream.

Trust anchor

trusted_outputs.md. Tiered registry; anchors the verification chain on USER-pinned outputs, not on tests.

Propagation map

dependency_graph.md. Phases / modules / plans / contracts + 13 data junctions (J1–J13). Tells the loop what to re-verify when something changes.

Termination

metrics.md + escalation.md. Definition of "better" + rollback triggers + perseveration limits (N=3 retries, M=5 stalled-slice).

Episodic memory

decisions.md + slice_contracts.md. Every decision + its rationale + the expected failure mode. Every shipped slice's prediction-vs-actual.

Lessons

anti_patterns.md — 14 cataloged traps (AP-001…AP-014) + the right move. Replaces "rediscover by failing" with "read the entry first."

Operational discipline

Critic separation

Every shipped slice gets verified by an Explore subagent — a separate read-only verifier with narrow scope. The slice author and the slice critic are different actors so the loop can't self-grade.

Visual diagnostics + smoke log

Any slice changing user-visible rendering files a diagnostic entry with a rendered PNG. Real-data smokes append to trackers/smoke_log.md with cohort + commit + outcome + bugs-revealed → fix-commit. Tests-green ≠ feature-works-on-real-data; the smoke log is the ground truth for real-data behavior.
