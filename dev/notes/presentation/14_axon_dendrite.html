Axon vs dendrite identification — milestone

Major roadmap milestone. The reconstruction stage currently treats every traced branch as an axon. Some traced branches are dendritic; signal-characteristics-based classification would let downstream analysis filter or stratify by type.

🎯 What we want
  • Per-branch label: axon / dendrite / unknown.
  • Either a per-branch column on the existing reconstruction output, or a new per-branch classification phase in the analysis stage.
  • Confidence score per branch — let downstream consumers threshold appropriately.
  • Stratified summary plots: arbor coverage by type, velocity distribution by type, branch-count histograms by type.
🧬 Discriminating signal characteristics
  • Conduction velocity: axons 0.3–1.0 m/s typical; dendrites slower (and back-propagating from soma, not forward).
  • Propagation direction: axons forward from soma to axon terminals; dendrites back-propagate into the arbor from soma.
  • Waveform polarity / shape: axonal spikes typically strongly biphasic with sharp negative peak; dendritic signals broader, attenuated, sometimes positive-leading.
  • Branch geometry: axonal arbors generally longer-distance + thinner; dendritic shorter + more proximal to soma.
  • Signal amplitude decay: axonal signal stays narrow + attenuates; dendritic signal broadens as it propagates.

Two paths to a v1 classifier

Path A — Heuristic ruleset (cheap, fast)
  1. Define 3–5 binary features from the list above (e.g. velocity_in_axon_range, propagation_outward_from_soma, waveform_sharp_biphasic).
  2. Score each branch on each feature using existing recon outputs (branches.json, branch_qc/propagations/*, gtr.pkl templates).
  3. Threshold-vote classifier: ≥3/5 axon-features → "axon"; ≤1/5 → "dendrite"; else "unknown".
  4. Ship as analysis-stage phase with config-knob thresholds; produce per-branch label TSV.

Pros: ships in <1 week. Honest about uncertainty (most branches → "unknown" initially). Cons: thresholds need tuning per cohort.

Path B — Trained classifier (gold-standard)
  1. Curate a labeled training set: ~50 visually-confirmed axon branches + ~50 visually-confirmed dendrite branches from the anchor cohort. Hand-labels via dashboard.
  2. Feature extraction: per-branch velocity, propagation linearity, waveform fwhm + amplitude, branch length + branching factor.
  3. Lightweight classifier (logistic regression / random forest); cross-validated.
  4. Ship as analysis-stage phase consuming the trained model; outputs per-branch label + confidence.

Pros: principled. Calibrated confidences. Cons: needs the labeled set (sit-down session with you to label ~100 branches via dashboard).
