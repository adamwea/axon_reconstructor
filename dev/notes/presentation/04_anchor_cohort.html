Why one cohort

🔬 Trust anchoring

Every algorithm change is compared against the same baseline outputs. Reduces variance to "algorithm change" only.

⏱️ Iteration speed

~30-min full reconstruct on one well. Multi-well runs are reserved for batch validation, not for slice development.

🔓 Scope discipline

Adding wells / cohorts requires explicit user gate — prevents over-fitting to non-representative data.

Read-only invariant: the reference data dir is NEVER mutated by iteration runs. New outputs go to /pscratch/sd/a/adammwea/dev_outputs/<plan_slice>/... and are compared against the reference, not on top of it.
