From HD-MEA voltage → axonal morphology

Spike-triggered averages of every electrode encode the propagation of the action potential down the axon arbor — if we can extract it.

📡 Input
  • MaxWell HD-MEA recordings — 26,400 electrodes, ~17.5 µm pitch, AxonTracking scan mode.
  • Devices: MaxTwo @ 10 kHz (current 80 k DMEM cohort), MaxOne @ 20 kHz, future ThreeBrain + Sony (device-agnostic by design).
  • Cell type: dissociated rat cortical cultures, DIV 6 → DIV 36+.
  • Per recording: 5–10 min of activity → 300–700 spike-sorted units, ~150–200 surviving QC.
🎯 Output
  • Per-unit axon arbor: branch trajectories, lengths, conduction velocities, soma location.
  • Per-well summary plots: chip layout with all arbors overlaid, circle-recon grid of every unit.
  • Cross-session: same unit tracked across DIVs (via unitlink / UnitMatchPy).
  • Population statistics: branch counts, velocity distributions, arbor sizes — via Dash dashboard.

Why this is hard

⚡ Signal

Axonal signals are 10–100× weaker than somatic spikes — need spike-triggered averaging over 100s–1000s of trials before peaks emerge from noise.

🧩 Crowding

Multi-unit recordings have overlapping arbors. Spike-sorting + post-sort merge (SLAy) must disambiguate before reconstruction.

🌀 Topology

Reconstruction means recovering a branching graph from sparse 2D voltage maps — connectivity is the goal, not just localization.

Status today: end-to-end pipeline runs reliably on the anchor cohort. 176-template baseline locks in spikesort + merge + reconstruction correctness. Current work: alternative reconstruction algorithm (Radivojevic 2023), cross-session matching, device generalization.
