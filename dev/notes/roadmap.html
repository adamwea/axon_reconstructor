axon_recon — development roadmap

Snapshot · May 2026
Era Theme What we built / are building Status Why it matters
1Foundation Reliable, reusable pipeline Cleaned out unused analysis steps. Standardized how parallel jobs allocate resources. Interrupted runs now resume cleanly instead of restarting from scratch. done Analyses are reproducible and recoverable. Less time lost to crashed jobs and re-running finished work.
2Extraction Focused tools Two new mini-tools split out of the main pipeline: one that packages spike-sorting outputs in a standard format other tools can read, and one that matches the same neurons across recordings on the same chip. done Same units can now be tracked across recordings. The new tools are reusable in other projects.
3Integration First end-to-end run Wire the new tools back into the main pipeline. Produce the first match tables that link individual units across recordings on the same culture / chip. in progress First scientific deliverable: follow individual neurons across repeated recordings of the same culture as it develops.
4Infrastructure Easier install & reproducibility One-command install for the development environment. Production container guaranteed to match what we run locally. Lower bar for collaborators to set up the pipeline on their own machine or compute cluster. in progress Easier onboarding for collaborators. Reproducible analyses across compute environments.
5Visualization Plots that tell a story Timeline grids of chip plots side-by-side across recordings, colored consistently by unit identity. Detailed single-recording plots showing each unit's electrode contributions, with color blending where electrodes contribute to multiple units. Per-unit videos of signal propagation along the axon. next Visually track how a culture's neural circuit changes over time. Understand individual-unit behavior in depth.
6Alternative method Second reconstruction algorithm Re-implement the reconstruction approach from Radivojevic et al. 2023 alongside our current method. Run both on the same data and compare results unit-by-unit. next Cross-validate findings between two independent methods. Potentially get more accurate axon reconstructions.
